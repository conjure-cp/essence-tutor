# Conjure Blocks
[Conjure Blocks](https://github.com/conjure-cp/conjure-blocks) has the potential to make learning Essence easier for beginners to the language and to programming in general. Essence Tutor could take advantage of this by offering learners the option to create models using it rather than writing text.

If Essence Tutor were to implement its own editor, particularly if the interface were to be web-based, then a toggle switch could be provided to switch between text-based editing and block-based editing. Since Conjure Blocks outputs Essence text, it would be able to translate relatively easily.

Some modifications to Conjure Blocks may be needed, however. Any team working on Essence Tutor would have to coordinate with those working on Conjure Blocks to adapt it to have an appropriate form for this project. For example, the user interface may need to be condensed to fit into a smaller portion of the screen.
