# User Testing
Informal and formal user testing can be carried out at the point at which Essence Tutor is usable software with enough content to teach the fundamentals.

Informal testing can be carried out within the VIP group or with those working with Essence on online courses. It can be carried out at an earlier stage, and requires less structure. With the feedback from this, Essence Tutor can be refined to serve its purpose as best as possible.

Formal testing should be carried out when the project is in a more substantial state, since has greater requirements. While proper planning should take place closer to the time at which testing is carried out, the trial should ask learners of varying experience to interact with Essence Tutor and give their opinions in relation to the interface and the content.

Ethics approval may be necessary to carry out formal user testing, particularly on a wider audience than the VIP. For this, those working on Essence Tutor should seek assistance from project members that have experience with the application process, as well as members of the Computer Science department that may be willing to assist.

With the feedback provided from user testing, Essence Tutor should be improved to ensure it is effective. In some circumstances, this may require changing how content is taught, how the interface functions and wording of notes.
