## How To Use This Guide
You can learn with Essence Tutor in one of two ways:

1. (Recommended) Use the command line tool to walk you through notes, automatically run your models and save your progress.
2. Work through the files within this directory yourself, running your models through Conjure or Conjure Oxide.

In either case, you can use the editor of your choice. If you're using Visual Studio Code, you may find it useful to install
the [Conjure plugin](https://marketplace.visualstudio.com/items?itemName=conjure.conjure-vs-code).

## What To Expect
Essence Tutor contains two types of material: notes and exercises. You will start by learning some concepts, and then will be
able to apply them by working with models. You'll be asked to both fix or modify existing models as well as to produce your
own models from scratch based on problem specifications.
